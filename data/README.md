# Parent hull

`Trawler_hull_maxsurf_model.3dm` is the parent hull used in this project. It is a MAXSURF/Rhino
version of the **"Small seiner-trawler" 3D model by I. Khlutchin**, published on GrabCAD.

- Original author: I. Khlutchin (GrabCAD community).
- Copyright and licence remain with the original author, under the terms of the GrabCAD
  platform where the model was published.
- The model is included here only for academic, non-commercial use, so that the code and tests
  of this coursework can be reproduced.
- It is **not** covered by the MIT licence of this repository (see `../LICENSE`).

If you are the author and want the model removed, please open an issue.
